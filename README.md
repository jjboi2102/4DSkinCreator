# 4DSkinCreator
resources for 4D skin creator app

a little tool i made to help with creating 4D skinpacks for minecraft: bedrock edition (with minimal vibecoding*)
this would not exist without BionicBen's 4D skinpack creation yt tutorial: https://www.youtube.com/watch?v=gz0juYtNUYo
and the skinpack template he made and features in that video

this script was written using autoit: https://www.autoitscript.com
and the updater script is obviously a windows batch file

idk if i will open-source the tool. probably not tho just because im lazy

*i used chatgpt to make a UUID generator bc idk how and was too lazy to research how. i also used chatgpt to help with some curl commands in the batch file, as well as reading from a file to a variable. other than that this is all hand-made by me with, as stated previously, the skinpack template from BionicBen
